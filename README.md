# SmartDesk

## Descripción

SmartDesk es una plataforma orientada a la gestión de activos tecnológicos,
mesa de ayuda, mantenimiento, personal, compras y reportes.

El proyecto busca centralizar la administración de los recursos tecnológicos
de una organización y facilitar la gestión de solicitudes de soporte técnico.

## Objetivo

Desarrollar una solución que permita gestionar de manera organizada los
activos tecnológicos, solicitudes de soporte, mantenimientos, usuarios,
compras y reportes.

## Funcionalidades principales

- Gestión de activos tecnológicos
- Mesa de ayuda y soporte técnico
- Gestión de personal, roles y permisos
- Mantenimiento preventivo y correctivo
- Reportes, analítica y dashboards
- Gestión de compras y proveedores

## Metodología

El proyecto utiliza la metodología Scrum para organizar el desarrollo,
utilizando Jira para la gestión del Product Backlog y GitHub para el
control de versiones y desarrollo.

## Herramientas

- Jira
- GitHub
- Git
- Visual Studio Code

## Identidad de Marca y Posicionamiento

### Manual de Marca
* **Nombre:** SmartDesk ERP
* **Eslogan:** Seguridad, eficiencia y soporte financiero integral.
* **Descriptor:** Gestión Financiera y Soporte Operativo.
* **Misión:** Optimizar la infraestructura tecnológica y la atención operativa en entidades financieras mediante una plataforma centralizada que garantice la continuidad del servicio y el control de activos.

### Arquitectura Visual
* **Escudo Francés:** Representa la protección institucional, la seguridad bancaria y la gestión de riesgos.
* **Headset / Audífonos:** Simbolizan el soporte técnico y la atención al cliente en la mesa de ayuda.
* **Bocadillo de Diálogo:** Representa la comunicación y la gestión fluida de tickets.
* **Marca de Verificación (Check):** Simboliza la resolución efectiva de incidentes y el cumplimiento de mantenimientos.
